# Market Map

A daily desk-grade **pre-market intelligence brief** that renders its own charts
as inline SVG and tracks + grades its own trade ideas over time.

The brief is **generated by Claude Code itself** — Claude does the web searches,
follows the strategist system prompt and 18-section spec in [`PROMPT.md`](PROMPT.md),
marks the trade book to market, renders the charts, and writes a self-contained
`output.html`. There is **no API key and no third-party dependency** — the Python
here is standard-library only.

## How it works

1. **`python main.py`** mints a session id and prints `Ready — paste this session ID into Claude Code`. That's all it does.
2. You tell Claude Code: **"run the Market Map"** (or double-click [`run.sh`](run.sh)).
3. Claude searches (≥16, allowlist in [`sources.py`](sources.py)), builds the `brief` dict, and drives the stdlib engine in [`book.py`](book.py) to render the page and persist state.

## Files

| File | Role |
|------|------|
| `main.py` | Launcher stub — prints the ready line + session id, then exits |
| `book.py` | Engine: trade-book persistence, mark-to-market, scoreboard, regime log, full inline-SVG HTML assembly (stdlib only) |
| `charts.py` | Pure-Python inline-SVG charts (equity curve, calibration, VIX term, yield curve) — no libs, no JS, no CDN |
| `sources.py` | Trusted-source allowlist |
| `PROMPT.md` | The operating prompt: workflow, system prompt, 18 sections, `brief` schema |
| `run.sh` | Double-click to trigger Claude Code to build today's brief |
| `trades.json` | Persistent trade book (open + closed) |
| `regime_log.json` | Dated log of regime-banner changes |
| `output.html` | The generated brief (created on each run) |

## The trade book

Every run marks open trades to market with directional P&L%, rolls stop/target
hits into the closed ledger, and allows discretionary close on a broken thesis —
but **never before `min_hold_days`** (≥30 on pre-position trades). The Live Book,
scoreboard, equity curve, and calibration chart all build off this state, so the
brief grades itself honestly over time.
