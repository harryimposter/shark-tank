How the conviction rating is built · /8 (four pillars, 0–2 each)
PillarWhat earns points
Asymmetry signal (0–2)Does the implied move misprice the historical average move, or is estimate dispersion unusually wide? 2 = clear mispricing of the event; 1 = moderate; 0 = none.
Sell-side consensus (0–2)Is the sell-side aligned — majority buy, upside to price target, positive revisions? 2 = strong support; 1 = mixed; 0 = contradicts. If unverified, conviction caps at Medium.
Catalyst clarity (0–2)Pre-print: is there an identifiable catalyst the consensus hasn't priced? Post-print: is the reaction disproportionate to the print (oversold/overbought)? 2 = clear edge; 1 = plausible; 0 = none.
Positioning & sentiment (0–2)Short interest >10% of float or an extreme positioning setup? 2 = extreme; 1 = notable lean; 0 = neutral/unavailable.
Label rules: High = score ≥6 with no pillar at 0 and all pillars sourced; High — data gap flagged = ≥6 but a pillar is estimated/unverified; Medium = 4–5 or any pillar 0 or consensus unverified; Low (<4) is excluded. Green/gold/red dots on each pillar = sourced / estimated / unverified.
